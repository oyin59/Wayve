# Wayve

Wayve is a place discovery app focused on helping people
find places that fit what they are actually looking for.

## Current Goal

Build the first working version of the discovery flow:

Filter → Match places → Results

## Technology

- React
- JavaScript
- Tailwind CSS
- Vite

## Current Features

- Preference-based filtering
- Place matching
- Results page
- Reusable option cards

## Planned Features

- Place details
- Search
- Map
- Saved places
- Reviews
- Community
